# Gorev-Takip-Uygulamasi---Omer-Faruk-Akturk
BLM2537 dersi projem olan "Görev Takip Uygulaması" nın geliştirmelerini buradan yapacağım

##  1. HAFTA

- Arayüz şablonu oluşturuldu.
- İleride kullanılacak görevler, ekleme sekmelerine geçiş eklendi.
- Section oluşturuldu ve anasayfa parçalara ayrıldı.
- Önemli kelimelere vurgu yapıldı.
- İleride CSS ile düzenlemeye yardımcı olacak span, class gibi kavramlar eklendi.
- Google Takvimler referans site olarak verildi.
- Mail sistemi eklendi.
- Copyright sembolü eklendi.

## 2. HAFTA

- Görevlerin listelendiği tablo yapısı oluşturuldu.
- 7 farklı sütun başlığı listelendi (ID,Görev,Kategori,Öncelik,Son Teslim,Durum,İşlemler).
- 3 farklı yapay veri kullanılarak arayüz test edildi.
- Dahili CSS kullanılarak, kullanıcıların dikkat etmesi gerektiği yerler vurgulandı (renklendirildi).
- Verileri düzenleme ve silme butonları eklendi (2. hafta itibariyle işlevsiz).
- Table footer ile tablodaki genel durum eklendi.

## 3. Hafta

- Verilerin toplanacağı sekmenin arayüzü oluşturuldu.
- Form oluşturuldu.
- Forma görevin adının yazılacağı input çerçevesi eklendi.
- Forma görevin kategorisinin ve öncelik durumunun seçenekleri eklendi.
- Tarih seçebilme eklendi.
- Görev için kısa notlar eklenebilen bir çerçeve eklendi.
- Submit ve reset kullanılarak veriyi kaydetme ve girilen değerleri sıfırlama seçenekleri eklendi.
- Veriler get metoduyla iletildi. 3. hafta itibariyle girilen form değerleri url üzerinde görüntülenir.
